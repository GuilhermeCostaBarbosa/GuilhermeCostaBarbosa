## Projetos

### 🤖 Automação de Cadastros — ERP Qualitor
Sistema RPA completo para ambiente hospitalar. Com a reforma tributária, centenas de itens precisavam ser cadastrados manualmente no Qualitor — um processo moroso que consumia horas da equipe. A solução lê uma planilha Excel, valida os dados, executa os cadastros em massa via Selenium headless e gera um relatório automático com o número de cada chamado aberto. Autenticação com Supabase e hash de senhas. Acessível pelo celular.

`Python` `Selenium` `Streamlit` `Supabase` `Pandas` `PostgreSQL` `Chromium Headless`

---

### 📦 Emissão e Envio Automático de Pedidos de Compra — SAP
Automação desktop completa integrada ao ERP SAP. A partir de uma planilha extraída do SAP (ME2N), o sistema gera e executa scripts VBScript que acessam o SAP GUI, emitem os pedidos de compra em PDF, salvam os arquivos automaticamente e os enviam por e-mail para os compradores responsáveis — tudo sem intervenção manual. Possui interface gráfica com barra de progresso desenvolvida em CustomTkinter.

`Python` `SAP GUI Scripting` `VBScript` `pywinauto` `pyautogui` `smtplib` `CustomTkinter` `Pandas`

---

### 🚀 API de Monitoramento & Pipeline CI/CD
Infraestrutura de observabilidade e CI/CD construída do zero. Uma API Flask coleta métricas reais de hardware (CPU, memória, disco) e as expõe para o Prometheus, que alimenta dashboards no Grafana com alertas automáticos via Discord. Todo o fluxo de testes e publicação da imagem Docker é automatizado via GitHub Actions — nenhum código quebrado chega à produção.

`Python` `Flask` `Docker` `Prometheus` `Grafana` `GitHub Actions` `Pytest` `Discord Webhooks`

---

### 📈 Dashboard de Cotações — Ibovespa (B3)
Dashboard interativo para acompanhamento de ações listadas no Ibovespa. Permite selecionar múltiplos ativos, filtrar períodos via slider e visualizar tanto o histórico de preços quanto a performance percentual de cada papel no período. Dados obtidos via yFinance com cache para melhor performance.

`Python` `Streamlit` `Pandas` `yFinance`

---

### 🍔 Hamburgueria Classic — Cardápio Digital
Aplicação web de cardápio digital com carrinho de compras funcional. O menu é renderizado dinamicamente via JavaScript, permite adicionar e remover itens com atualização em tempo real do total, e finaliza o pedido enviando automaticamente a lista para o WhatsApp da lanchonete.

`HTML` `CSS` `JavaScript`
